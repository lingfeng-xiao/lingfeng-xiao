# A small job, done properly.

I'm Lingfeng, a Java backend developer with around four years of experience. My background includes Spring Boot, SQL, Redis, RocketMQ, transactions, and reliability work. I'm exploring AI agent engineering, too.

For freelance work, I focus on tasks with a clear finish line:

- Diagnose and fix a reproducible Spring Boot / REST API bug, with a regression test.
- Investigate a slow SQL query and explain the proposed change and how to verify it.
- Automate a repetitive data-processing or API integration task.

I have 8–16 hours a week available, mainly on weekends. I can reply to messages on weekdays. Written English works best for me; please agree on any meeting requirements before we start.

## What you receive

A scoped change, instructions to run it, relevant tests, and a short explanation of what changed and what still needs checking. For a diagnosis, the deliverable is the evidence and findings; implementation can be a separate milestone.

Before a quote, I need a reproducible example or sample input, the expected result, and the deadline. A small paid milestone is a good place to start. Access credentials should stay in the client's approved secure channel.
